# CHelpProject
# Иду на помощь!

Веб-портал для организации бытовой помощи пожилым людям
и людям с ограниченной мобильностью во Владивостоке.

## О проекте

Проект направлен на упрощение взаимодействия между
людьми, которым требуется бытовая помощь, волонтёрами
и координаторами.

Основная задача сервиса — обеспечить создание заявок,
поиск исполнителей, назначение волонтёров и отслеживание
выполнения поручений.

## Основные роли

- Получатель помощи — создаёт заявки и отслеживает их.
- Волонтёр — просматривает заявки и выполняет поручения.
- Координатор — управляет заявками и назначает исполнителей.

## Функциональность MVP

- Регистрация и авторизация.
- Пользовательские профили.
- Создание и редактирование заявок.
- Каталог доступных заявок.
- Отклики волонтёров.
- Назначение исполнителей координатором.
- Отслеживание статусов заявок.
- История выполненных поручений.
