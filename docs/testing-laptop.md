# Тестовый стенд с ноутбука (бесплатно)

Сайт запускается на своём компьютере, а туннель Cloudflare даёт ему публичную ссылку
`https://случайные-слова.trycloudflare.com`. Регистрация, домен и открытые порты не нужны.

```
Тестировщик ──https──▶ Cloudflare ──туннель──▶ ноутбук: frontend :3000 ──/api/*──▶ backend :3001 ──▶ PostgreSQL
```

Наружу виден только frontend; запросы `/api/*` он сам пересылает на backend (`rewrites` в `next.config.ts`).

## Один раз

1. Всё из раздела «Запуск backend без Docker» в README: Node.js 22, PostgreSQL, `backend/.env`,
   миграции и seed. `npm install` в `backend` и `frontend`.
2. Установить туннель:

   ```powershell
   winget install --id Cloudflare.cloudflared
   ```

## Каждый раз перед тестированием

1. Запустить PostgreSQL, если он не служба Windows.
2. В корне репозитория:

   ```powershell
   .\scripts\start-test.ps1
   ```

   Скрипт собирает backend и frontend (3–5 минут), запускает их, открывает туннель и крупно показывает ссылку —
   она уже скопирована, остаётся вставить в чат тестировщикам вместе с [testing.md](testing.md).
   Если код не менялся с прошлого раза — `.\scripts\start-test.ps1 -NoBuild` (запуск за 15 секунд).
3. Не закрывать окно, пока идёт тестирование. **Ctrl+C** — остановить всё.

## Что важно знать

| | |
|---|---|
| Ссылка | **новая при каждом запуске** — присылать заново |
| Ноутбук | не должен засыпать: Параметры → Система → Питание → «Переводить в спящий режим» → «Никогда» (при питании от сети) |
| Данные | тестировщики работают с вашей локальной базой. Сбросить к тестовым: `cd backend; npx prisma migrate reset --force` |
| Плашка | на всех страницах «Тестовый стенд. Не вводите настоящие данные» |
| Лимит запросов | на время теста выключен: через туннель все приходят с одного адреса |
| Журналы | `%TEMP%\idu-help-test\` — backend, frontend, туннель |

## Если не работает

| Симптом | Что сделать |
|---|---|
| «Порт 3000 уже занят» | закрыть другой запущенный сайт (`npm run dev`, прошлый запуск) |
| «Backend не запустился» | не запущен PostgreSQL или неверный `DATABASE_URL` в `backend\.env` — смотреть журнал |
| Ссылка не появляется больше минуты | `%TEMP%\idu-help-test\tunnel.log`; Cloudflare бывает недоступен — повторить позже или использовать tuna.am |
| У тестировщика ошибка 1033 / 530 | окно со скриптом закрыто или ноутбук уснул |
