# Логотип и маскот

| Файл | Что это |
|---|---|
| `logo.png`, `../../frontend/public/brand/logo.svg` | Логотип: знак и название |
| `mark.png`, `../../frontend/public/brand/mark.svg` | Знак отдельно (иконка вкладки, аватар в соцсетях) |
| `mascot.png`, `../../frontend/public/brand/mascot.svg` | Маскот «Амурчик» |

**Знак** — сердце, которое спешит: линии движения слева означают «иду». Квадрат — фирменный
оранжевый `#B94A00` (контраст с белым 5,2:1), сердце белое. Знак читается и в размере 16 px.

**Маскот «Амурчик»** — тигрёнок-волонтёр. Амурский тигр — символ Приморья, где работает сервис.
На нём синий жилет волонтёра со значком-сердцем, в руке пакет с продуктами — самое частое поручение.
Маскот машет рукой — встречает и подбадривает. Он есть на главной, на странице 404 и в пустых списках.

В версии для слабовидящих знак перекрашивается в цвета выбранной схемы, а маскот (это изображение)
становится чёрно-белым или скрывается — по настройке «Изображения».
